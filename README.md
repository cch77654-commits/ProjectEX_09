# ProjectEX_09

Unreal Engine 5.5 기반 멀티플레이어 숫자야구(Mastermind) 게임입니다.

## 게임 방법
- 1~9 중 중복되지 않는 숫자 3개를 채팅으로 입력합니다 (예: `123`).
- 서버가 정한 정답과 비교해 Strike/Ball 결과(`1S2B` 등)를 모든 플레이어에게 보여줍니다.
- 숫자 3자리 형식이 아니면 본인에게만 "다시 입력하세요"가 표시됩니다.
- 3 Strike를 맞히면 게임이 리셋되고 새 정답이 생성됩니다.

## 실행 방법
- 에디터에서 Play 시 Net Mode를 "Play As Listen Server"로 설정하고 플레이어 수를 2 이상으로 지정합니다.
